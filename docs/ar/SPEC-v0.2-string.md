# MSF Lang v0.2 — إضافة النصوص (مسودة)

**الحالة:** مسودة مرافق لـ [`SPEC-v0.2-practical.md`](SPEC-v0.2-practical.md). الإنجليزية مرجعية.

## المدمجات

| الاسم | عدد الوسائط | المعنى |
|---|---|---|
| `upper(s)` | 1 | تحويل إلى أحرف كبيرة |
| `lower(s)` | 1 | تحويل إلى أحرف صغيرة |
| `trim(s)` | 1 | إزالة المسافات البادئة/اللاحقة |
| `contains(s, sub)` | 2 | اختبار احتواء فرعي (ordinal) |
| `startsWith(s, sub)` | 2 | اختبار بادئة |
| `endsWith(s, sub)` | 2 | اختبار لاحقة |
| `split(s, delimiter)` | 2 | تقسيم إلى `list`؛ لا يجوز حد فاصل فارغ |

نوع الوسائط يجب أن يكون `string`؛ غير ذلك يؤدي إلى `E4009`.
