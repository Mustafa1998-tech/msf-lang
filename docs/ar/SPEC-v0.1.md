# مواصفات لغة MSF Lang الإصدار 0.1

**الاسم الرمزي:** Seed
**إصدار المواصفات:** `0.1.0-draft.1`
**التاريخ:** 2026-11-16
**الحالة:** مسودة للاعتماد. المحرك غير مُنفَّذ بعد.
**المرجع المعياري:** تحدد هذه الوثيقة لغة MSF Lang الإصدار 0.1. تُصان النسخة العربية
والنسخة الإنجليزية معًا؛ وإذا حدث تعارض بينهما فالنسخة الإنجليزية هي المرجع المعياري
مؤقتًا حتى يُصحَّح التعارض في الملفين.

تُستخدم الكلمات **يجب** و**لا يجوز** و**ينبغي** و**يجوز** وفق المعاني الواردة في RFC 2119.

---

## 1. الغرض والنطاق

MSF Lang لغة برمجة عامة الأغراض، صغيرة الحجم، ديناميكية الأنواع، صُممت لتكون:

- **قابلة للتنفيذ من الصفر.** يكفي لبنائها معجم (Lexer) يدوي، ومحلل نحوي تنازلي تعاودي
  (Recursive-Descent Parser)، ومحلل دلالي (Resolver)، ومفسّر شجري (Tree-Walk Interpreter).
- **قابلة للتنبؤ.** ترتيب التقييم، والنطاقات، وسلوك الأعداد، ومواضع الأخطاء كلها محددة.
- **قابلة للتشخيص.** كل خطأ لغوي يحمل رمزًا ثابتًا، ورقم سطر وعمودًا يبدآن من 1، ومقتطفًا
  من المصدر.
- **قابلة للاختبار.** لكل ميزة في هذه الوثيقة اختبار صندوق أسود يمكن كتابته كبرنامج `.msf`
  مع مخرجات متوقعة أو تشخيص متوقع.
- **قابلة للتوسع دون كسر برامج 0.1.** الميزات المؤجلة مذكورة صراحةً، ولا تُضاف بصمت.

الإصدار 0.1 صغير عمدًا. هو نواة لغة مكتملة، وليس مكتبة قياسية أو بيئة تشغيل إنتاجية.

### 1.1 داخل النطاق

| المجال | المشمول |
|---|---|
| القيم | `number` منتهٍ، `string`، `boolean`، `nil` |
| الارتباطات | `let` (ارتباط غير قابل لإعادة الإسناد)، `var` (قابل للإسناد)، نطاقات الكتل |
| الحساب | `+ - * / %`، والسالب الأحادي `-` |
| النصوص | محارف نصية بعلامات اقتباس مزدوجة، خمسة تهريبا، ودمج بـ `+` |
| المنطق | `and`، `or`، `not`، مع تقييم قصير الدائرة |
| المقارنة | `== != < <= > >=` |
| التحكم | `if`، `else if`، `else` |
| الدوال | دوال مسماة على المستوى الأعلى، بعدد معاملات ثابت، واستدعاء ذاتي، و`return` |
| الإخراج | الدالة المدمجة `print` |
| الأدوات | `msf run`، `msf repl`، `--help`، `--version` |
| التشخيص | رموز ثابتة، سطر وعمود، مقتطف مصدر، ورموز خروج موثقة |

### 1.2 خارج النطاق صراحةً

الحلقات، والمصفوفات، والقواميس، والأنواع المعرفة من المستخدم، والإغلاقات (Closures)،
والدوال كقيم من الدرجة الأولى، والدوال المجهولة، والوحدات، والاستيراد، والاستثناءات،
وإدخال المستخدم، والملفات، والشبكات، ومكتبة قياسية تتجاوز `print`، ومعاملات سطر الأوامر
للبرنامج، وتوصيفات الأنواع، وتهريبا Unicode، والأسس العددية، والتعافي من أخطاء متعددة،
وتتبّع المكدس، والألوان في التشخيص، وخادم LSP، والمنسّق، والمنقّح، والبايت كود، والآلة
الافتراضية، والمترجم الفوري. راجع سجل القرارات
[`docs/DECISIONS.md`](../DECISIONS.md) لسجل الميزات المؤجلة الكامل.

## 2. مبادئ التصميم

1. **طريقة واحدة واضحة لكتابة التعليمة.** الأقواس المعقوفة والفواصل المنقوطة إلزامية،
   وفواصل الأسطر لا معنى لها. لا يوجد إدراج تلقائي للفاصلة المنقوطة.
2. **لا تحويلات ضمنية.** `"a" + 1` خطأ، وليس `"a1"`. الدالة `print` وحدها تحوّل القيم
   إلى نص للعرض.
3. **لا مفهوم "الصدق" (Truthiness).** الشروط والمعاملات المنطقية تتطلب قيم `boolean`.
   `if (1)` خطأ.
4. **الجمود هو الأصل على مستوى الارتباط.** `let` هي التعليمة الطبيعية، و`var` هي الموافقة
   الصريحة على إعادة الإسناد.
5. **الفشل السريع.** الإصدار 0.1 يبلّغ عن أول خطأ في أول مرحلة فاشلة، ولا يحاول التعافي
   أو عرض أخطاء متتابعة.
6. **الحتمية.** لا توجد في 0.1 ساعة ولا عشوائية ولا إدخال ولا وصول إلى البيئة ولا تزامن،
   لذا فإن المصدر نفسه والمعاملات نفسها ينتجان المخرجات نفسها دائمًا.
7. **المواضع جزء من العقد.** كل رمز (Token) وكل عقدة في شجرة التجريد تحمل مدى نصيًا. لا
   يُستنتج رقم السطر والعمود من رسالة منسّقة.

## 3. النص المصدري والبنية المعجمية

### 3.1 الترميز

- يجب أن تكون ملفات المصدر بترميز UTF-8.
- يجب قبول علامة BOM (`EF BB BF`) في بداية الملف وتجاهلها.
- أي محرف U+FEFF في موضع آخر هو محرف غير متوقع (`E1001`).
- UTF-8 غير الصالح خطأ إدخال/إخراج (`E5005`، رمز الخروج 4)، وليس خطأ لغويًا.
- النص المصدري سلسلة من قيم Unicode القياسية (Scalar Values). لا يجوز للمنفّذ تقسيم زوج
  بديل (Surrogate Pair) عند حساب العمود.

### 3.2 نهايات الأسطر والمواضع

- `LF` (U+000A) و`CRLF` (U+000D U+000A) و`CR` المنفرد (U+000D) كل منها يمثل فاصل سطر
  واحدًا.
- يبدأ ترقيم الأسطر من **1**.
- يبدأ ترقيم الأعمدة من **1**، ويُحسب بعدد قيم Unicode القياسية، لا بالبايتات ولا بوحدات
  UTF-16.
- تُحسب علامة الجدولة (Tab) عمودًا **واحدًا**. عند رسم المؤشر تحت علامة جدولة، يحافظ
  العارض على علامات الجدولة في البادئة حتى تبقى محاذاة محطات الجدولة صحيحة.
- مدى الرمز هو `[start, end)`. موضع البداية هو أول محرف في الرمز، وموضع النهاية عمود واحد
  بعد آخر محرف.
- يقع رمز نهاية الملف (EOF) مباشرة بعد آخر محرف في المصدر.

### 3.3 الفراغات والتعليقات

الفراغات هي أي تسلسل من:

- المسافة `U+0020`
- الجدولة الأفقية `U+0009`
- تغذية السطر `U+000A`
- إرجاع العربة `U+000D`

لا تُقبل أي فراغات Unicode أخرى؛ مثلًا U+00A0 يعطي `E1001`.

التعليقات تُعامل كفراغات:

- `//` يبدأ تعليق سطر ينتهي قبل فاصل السطر التالي أو عند EOF.
- `/*` يبدأ تعليق كتلة ينتهي عند أول `*/`.
- تعليقات الكتل **لا تتداخل**. في `/* a /* b */ c` ينتهي التعليق عند أول `*/`، ثم يكون
  `c` كودًا مصدريًا.
- تعليق الكتلة غير المنتهي يعطي `E1005` عند `/*` الافتتاحية.

### 3.4 المعرّفات

```ebnf
identifier = identifier-start, { identifier-part } ;
identifier-start = "A".."Z" | "a".."z" | "_" ;
identifier-part  = identifier-start | "0".."9" ;
```

المعرّفات ASCII فقط، وحساسة لحالة الأحرف. المعرّفات غير الإنجليزية مؤجلة. `total` و`Total`
و`_total2` معرّفات مختلفة.

### 3.5 الكلمات المحجوزة

الكلمات التالية محجوزة ولا يجوز استخدامها كمعرّفات:

```text
let  var  fn  if  else  return  true  false  nil  and  or  not
```

`print` ليست كلمة محجوزة، بل اسم دالة مدمجة محجوز بقواعد إعلان خاصة (القسم 10). جميع
الكلمات المحجوزة بأحرف صغيرة وحساسة لحالة الأحرف.

### 3.6 الأعداد

```ebnf
number = digit, { digit }, [ ".", digit, { digit } ] ;
digit  = "0".."9" ;
```

- `42` و`0` و`3.14` صالحة.
- `.5` و`5.` و`1e3` و`0x10` و`1_000` و`+5` ليست أعدادًا صالحة. `.5` و`5.` يفشلان
  معجميًا/نحويًا؛ والأس والست عشري والفاصل `_` والإشارة البادئة مؤجلة.
- تُقرأ القيمة كعدد IEEE-754 binary64 (`double`) بتقريب إلى الأقرب.
- العدد الذي لا ينتج قيمة منتهية يعطي `E1002`.
- الأعداد السالبة تتكون من العامل الأحادي `-`، وليست جزءًا من العدد.

### 3.7 النصوص

```ebnf
string  = '"', { string-char | escape }, '"' ;
escape  = "\\", ( "n" | "t" | "r" | "\\" | '"' ) ;
```

- النصوص بين علامتي اقتباس مزدوجتين، ولا يجوز أن تحتوي فاصل سطر خامًا. فاصل السطر الخام
  قبل علامة الإغلاق يعطي `E1003` عند علامة الفتح.
- التهريبا المدعومة: `\n` (LF)، `\t` (جدولة)، `\r` (CR)، `\\` (شرطة مائلة عكسية)،
  `\"` (علامة اقتباس).
- أي تهريب آخر، بما فيه `\0` و`\x41` و`\u{1F600}`، يعطي `E1004` عند الشرطة العكسية.
- النصوص قيم غير قابلة للتغيير. تمثيلها الداخلي تفصيل تنفيذي، لكن المساواة معرفة في
  القسم 5.4.
- يجوز أن يحتوي النص أي قيمة Unicode قياسية أخرى، بما فيها العربية والرموز التعبيرية.

### 3.8 علامات الترقيم والمعاملات

```text
(  )  {  }  ,  ;
+  -  *  /  %
==  !=  <  <=  >  >=
=
```

هذه هي الرموز الصالحة في 0.1، إضافة إلى بادئي التعليقات `//` و`/*`. النقطة `.` صالحة فقط
داخل عدد. المحارف `!` منفردة و`?` و`&` و`|` و`[` و`]` و`:` و`@` و`#` و`$` و`^` و`~`
والشرطة العكسية خارج نص كلها غير متوقعة (`E1001`).

### 3.9 أخطاء معجمية

| الرمز | الحالة | الموضع |
|---|---|---|
| `E1001` | محرف غير صالح في هذا الموضع | المحرف |
| `E1002` | عدد غير منتهٍ | العدد |
| `E1003` | نص غير منتهٍ | علامة `"` الافتتاحية |
| `E1004` | تسلسل تهريب غير صالح | الشرطة العكسية |
| `E1005` | تعليق كتلة غير منتهٍ | `/*` الافتتاحية |

يتوقف المعجم عند أول خطأ معجمي ولا يُصدر أي رموز.

## 4. القواعد النحوية

القواعد LL(1) مع نظرة أمامية صغيرة لكشف الإسناد. `EOF` رمز نهاية الملف. الأقواس
المعقوفة `{ ... }` في EBNF تعني تكرارًا، والأقواس المربعة `[ ... ]` تعني اختياريًا.

```ebnf
program        = { declaration }, EOF ;

declaration    = function-decl
               | variable-decl
               | statement ;

function-decl  = "fn", identifier, "(", [ parameters ], ")", block ;

parameters     = identifier, { ",", identifier } ;

variable-decl  = ( "let" | "var" ), identifier, "=", expression, ";" ;

statement      = if-stmt
               | return-stmt
               | block
               | assignment-stmt
               | expression-stmt ;

if-stmt        = "if", "(", expression, ")", block,
                 [ "else", ( if-stmt | block ) ] ;

return-stmt    = "return", [ expression ], ";" ;

block          = "{", { declaration }, "}" ;

assignment-stmt = identifier, "=", expression, ";" ;

expression-stmt = expression, ";" ;

expression     = logic-or ;

logic-or       = logic-and, { "or", logic-and } ;

logic-and      = equality, { "and", equality } ;

equality       = comparison, { ( "==" | "!=" ), comparison } ;

comparison     = term, { ( "<" | "<=" | ">" | ">=" ), term } ;

term           = factor, { ( "+" | "-" ), factor } ;

factor         = unary, { ( "*" | "/" | "%" ), unary } ;

unary          = ( "-" | "not" ), unary
               | call-or-primary ;

call-or-primary = identifier, [ "(", [ arguments ], ")" ]
                | primary ;

arguments      = expression, { ",", expression } ;

primary        = number
               | string
               | "true"
               | "false"
               | "nil"
               | identifier
               | "(", expression, ")" ;
```

### 4.1 ملاحظات القواعد

- لا توجد تعليمة فارغة. الفاصلة المنقوطة المنفردة `;` خطأ نحوي.
- لا توجد فاصلة زائدة في قوائم المعاملات أو الوسائط.
- الفواصل المنقوطة إلزامية بعد كل إعلان متغير، و`return`، وإسناد، وتعليمة تعبير. ولا
  تُستخدم بعد الكتل أو إعلانات الدوال.
- يجوز أن تحتوي الكتلة إعلانات وتعليمات، بما فيها `fn` متداخلة. تُحلَّل الدالة المتداخلة
  نحويًا لكن يرفضها المحلل الدلالي (`E3007`).
- syntactically، يتطلب الاستدعاء معرّفًا يليه `(` مباشرة. `(f)(1)` و`f()()` خطأ نحوي،
  لأن الدوال ليست قيمًا من الدرجة الأولى في 0.1.
- `else` يرتبط بأقرب `if` غير مرتبط. و`else if` يُحلَّل كـ `if-stmt` داخل فرع `else`.
- `return` بلا تعبير يعيد `nil`. وفاصل السطر بعد `return` لا ينهيه؛ فواصل الأسطر لا معنى لها.
- `not` كلمة محجوزة وليست دالة. `not not true` صالح.
- المعاملات الأحادية يمينية الترابط. جميع المعاملات الثنائية يسارية الترابط.
- التعبير غير الاسمي المتبوع بـ `=` يعطي `E2011` (هدف إسناد غير صالح) بدلًا من خطأ
  فاصلة منقوطة عام.

### 4.2 أسبقية المعاملات

من الأعلى إلى الأدنى:

| المستوى | المعاملات | الترابط | المعنى |
|---|---|---|---|
| 1 | `f(...)` | — | استدعاء (لمعرّف فقط) |
| 2 | `-` (أحادي)، `not` | يمين | سالب عددي، نفي منطقي |
| 3 | `*` `/` `%` | يسار | ضرب، قسمة، باقٍ |
| 4 | `+` `-` | يسار | جمع، طرح، دمج نصوص |
| 5 | `<` `<=` `>` `>=` | يسار | مقارنة عددية |
| 6 | `==` `!=` | يسار | مساواة |
| 7 | `and` | يسار | و-logical قصير الدائرة |
| 8 | `or` | يسار | أو-logical قصير الدائرة |

الأقواس تتجاوز الأسبقية. المقارنات لا تتسلسل: `1 < 2 < 3` تُحلَّل كـ `(1 < 2) < 3`
وتفشل وقت التشغيل بـ `E4004`، لأن المعامل الأيسر قيمة منطقية.

### 4.3 حد التداخل

لمنع ملف مصدري مشوّه من إسقاط عملية المضيف، يجب أن يفرض المحلل النحوي حدًا أقصى للتداخل
هو **256** للتعبيرات والكتل وسلاسل `if`/`else`. يُحسب الحد من البنية الخارجية. تجاوزه
يعطي `E2013` عند الرمز الافتتاحي الذي كان سيتجاوز الحد. البرنامج الصالح ذو 256 قوسًا
متداخلًا أو 256 كتلة متداخلة مقبول، و257 مرفوض. هذا حد سلامة للمحلل، وليس ميزة لغوية.

### 4.4 قيود على مستوى القواعد

الأمور التالية أخطاء نحوية، وليست أخطاء دلالية:

- غياب `)` أو `}` أو `;` أو `{` أو `=` حيث يجب.
- إعلان دالة بلا `(` أو بلا جسم.
- `if` بلا أقواس.
- `else` بلا `if` سابق في التعليمة نفسها.
- تعليمة تعبير تنتهي بمعامل، مثل `1 + ;`.
- استدعاء بوسيطة فارغة بين فاصلتين، مثل `f(1, , 2)`.
- استخدام `return` كتعبير، مثل `let x = return 1;`.
- استخدام الإسناد كتعبير، مثل `let y = (x = 1);`.
- استخدام كلمة محجوزة حيث يلزم معرّف.

## 5. القيم والأنواع

### 5.1 أنواع القيم

| اسم النوع | الوصف | أمثلة |
|---|---|---|
| `number` | عدد IEEE-754 binary64 منتهٍ | `0`، `-12`، `3.5` |
| `string` | نص Unicode غير قابل للتغيير | `"MSF"`، `"مرحبا"` |
| `boolean` | قيمة منطقية | `true`، `false` |
| `nil` | القيمة الوحيدة لغياب القيمة | `nil` |
| `function` | دالة داخلية قابلة للاستدعاء، وليست قيمة لغوية | دالة معلنة بـ `fn` |
| `builtin` | دالة داخلية معرفة مسبقًا | `print` |

`function` و`builtin` **ليستا** قيمتين من الدرجة الأولى في 0.1. لا يجوز أن يظهر اسم
مرتبط بإحداهما إلا كدالة مستدعاة في استدعاء. استخدامه في موضع قيمة يعطي `E3010`.

### 5.2 الأعداد

- جميع الأعداد قيم `double`.
- NaN واللانهاية ليستا قيمتين صالحتين في MSF Lang. العدد غير المنتهي يعطي `E1002`،
  ونتيجة حسابية غير منتهية تعطي `E4006`.
- `0` و`-0` متساويان وكلاهما يُعرض `0`. لا تميّز اللغة الصفر الموقّع فيما عدا ذلك.
- لا يوجد نوعان منفصلان للأعداد الصحيحة والعشرية.

### 5.3 النصوص

- النصوص متتاليات Unicode قياسية غير قابلة للتغيير.
- المساواة ترتيبية وتقارن تسلسل القيم القياسية نفسه.
- الدمج بـ `+` ينشئ نصًا جديدًا. يجب أن يكون المعاملان نصين.
- لا توجد فهرسة ولا طول ولا تقطيع ولا استيفاء (Interpolation) ولا دوال نصية في 0.1.

### 5.4 المساواة

`==` و`!=` معرفتان لكل زوج من القيم اللغوية:

1. إذا اختلف اسم النوع، تكون `==` قيمتها `false` و`!=` قيمتها `true`.
2. إذا كان كلا المعاملين `number`، تُقارن المساواة العددية IEEE-754.
3. إذا كان كلا المعاملين `string`، يُقارن تسلسل القيم القياسية ترتيبيًا.
4. إذا كان كلا المعاملين `boolean`، تُقارن القيمتان المنطقيتان.
5. إذا كان كلا المعاملين `nil`، تكون `==` قيمتها `true`.

لا ترفع المساواة خطأ وقت تشغيل أبدًا. لا تظهر الدوال أو الدوال المدمجة كمعاملات لأنها
ليست قيمًا.

### 5.5 تنسيق العرض

تستخدم `print` والـ REPL قواعد تحويل القيم إلى نص التالية:

| القيمة | النص |
|---|---|
| number | تمثيل ذهاب-وعودة (round-trip) بثقافة ثابتة؛ `-0` يُعرض `0`؛ القيم الصحيحة تُعرض بلا `.0` |
| string | محتوى النص بلا علامات اقتباس |
| boolean | `true` أو `false` |
| nil | `nil` |

بالنسبة للأعداد، يجب أن ينتج المنفّذ أقصر نص يعود إلى العدد `double` نفسه، باستخدام `.`
كفاصل عشري، وحرف `e` صغيرًا للترميز العلمي، دون إشارة `+` ودون أصفار بادئة في الأس
(مثل `1e20` و`1.5e-7`). توثّق خطة التنفيذ صيغة .NET الدقيقة التي يستخدمها المنفّذ المرجعي.

## 6. الأسماء والارتباطات والنطاقات

### 6.1 النطاقات

تستخدم MSF Lang نطاقات معجمية مبنية على الكتل:

- **النطاق العام** يحتوي الدالة المدمجة `print` وجميع الإعلانات على المستوى الأعلى.
- كل كتلة `{ ... }` تنشئ نطاقًا فرعيًا، بما فيها جسم فرع `if`، والكتلة المستقلة، وجسم
  الدالة.
- نطاق جسم الدالة يحتوي معاملاتها وإعلاناتها المحلية. المعاملات والمتغيرات المحلية تشترك
  في نطاق واحد.
- البحث عن الاسم يسير من النطاق الحالي إلى الخارج حتى النطاق العام. لا يوجد نطاق ديناميكي
  ولا وصول إلى متغيرات محلية للمستدعي.
- لا يكون الإعلان مرئيًا إلا بعد تقييم مُهيّئه. لذلك يمكن لإعلان داخلي أن يحجب ارتباطًا
  خارجيًا في مُهيّئه:

  ```msf
  let x = 1;
  {
      let x = x + 1;  // يُقرأ x الخارجي؛ ويصبح x الجديد مرئيًا بعد هذا السطر
      print(x);      // 2
  }
  print(x);          // 1
  ```

  إذا لم يوجد `x` خارجي، فإن `let x = x;` يعطي `E3001` عند `x` في المُهيّئ.

### 6.2 الإعلانات

- `let name = expr;` ينشئ ارتباطًا غير قابل للإسناد. يشير الارتباط دائمًا إلى القيمة نفسها؛
  والقيمة نفسها غير قابلة للتغيير في جميع أنواع 0.1.
- `var name = expr;` ينشئ ارتباطًا قابلًا للإسناد، ويمكن إسناده قيمة من أي نوع لاحقًا.
- مُهيّئ الإعلان إلزامي.
- لا يجوز إعلان الاسم أكثر من مرة في النطاق نفسه (`E3002`).
- حجب اسم من نطاق خارجي مسموح.
- `print` اسم مدمج محجوز ولا يجوز إعلانه في أي نطاق (`E3004`).
- المتغيرات والدوال على المستوى الأعلى تشترك في نطاق واحد، فلا يجوز أن يحمل متغير ودالة
  الاسم نفسه في النطاق العام.
- يجوز لمتغير محلي أن يحجب دالة عامة. عندئذٍ يُحلّ الاستدعاء إلى المتغير ويُرفض بـ `E3009`.

### 6.3 الإسناد

الإسناد تعليمة وليس تعبيرًا:

```msf
var count = 0;
count = count + 1;
```

- يجب أن يكون الطرف الأيسر معرّفًا واحدًا.
- يجب أن يُحلّ الاسم إلى ارتباط موجود (`E3001`).
- الإسناد إلى ارتباط `let` يعطي `E3005`.
- الإسناد إلى دالة أو إلى `print` يعطي `E3006`.
- يُقيَّم الطرف الأيمن أولًا، ثم يُحدَّث الارتباط.
- الإسناد إلى معامل مسموح؛ المعاملات ارتباطات محلية قابلة للإسناد.

### 6.4 رؤية الأسماء العامة داخل الدوال

إعلانات الدوال **ليست** مرفوعة في 0.1:

- لا يجوز استدعاء دالة إلا بعد معالجة إعلان `fn` الخاص بها بترتيب النص.
- يجوز لجسم الدالة الإشارة إلى متغير عام أو دالة عامة معلنة **قبل** إعلان الدالة. ولا
  يجوز الإشارة إلى ما هو معلن لاحقًا، حتى لو حدث الاستدعاء لاحقًا. هذه الإشارة تعطي
  `E3001`.
- يجوز لجسم الدالة استدعاء نفسه، ما يتيح الاستدعاء الذاتي المباشر.
- الاستدعاء المتبادل غير ممكن في 0.1 لأن الدالة الثانية لا ترى الأولى إلا إذا كانت الأولى
  معلنة قبلها، والأولى لا ترى الثانية. هذا مقصود؛ راجع سجل الميزات المؤجلة.

مثال:

```msf
let base = 10;

fn addBase(n) {
    return n + base;   // صالح: base معلنة قبل addBase
}

fn later() {
    return helper();   // E3001: helper معلنة بعد later
}

fn helper() {
    return 1;
}

print(addBase(5));     // 15
```

### 6.5 الأسماء غير المعرفة وغير المهيأة

- لا توجد متغيرات محلية غير مهيأة: كل إعلان له مُهيّئ.
- الاسم غير المعلن عند موضع الإشارة يعطي `E3001`.
- لأن الدوال ليست مرفوعة، فإن الاستدعاء قبل إعلانها يعطي `E3001`، وليس خطأ وقت تشغيل.
- لا توجد قيمة `undefined` ولا تهيئة ضمنية بـ `nil`.

## 7. التعابير

### 7.1 ترتيب التقييم

- تُقيَّم معاملات المعاملات الثنائية من اليسار إلى اليمين.
- تُقيَّم وسائط الاستدعاء من اليسار إلى اليمين، ثم يحدث الاستدعاء.
- `and` و`or` تقيّمان المعامل الأيسر أولًا وتستخدم القصر؛ لا يُقيَّم المعامل الأيمن إذا
  كانت النتيجة محسومة.
- تُقيَّم معاملات العوامل الأحادية قبل تطبيق العامل.
- الإسناد يقيّم طرفه الأيمن، ثم يخزن.
- لا يوجد ترتيب تقييم غير محدد.

### 7.2 الحساب

ليكن `T` نوع المعامل وقت التشغيل.

| التعبير | الأنواع المطلوبة | النتيجة | الخطأ عند عدم التطابق |
|---|---|---|---|
| `a + b` | عددان أو نصان | مجموع أو دمج | `E4004` |
| `a - b` | عددان | فرق | `E4004` |
| `a * b` | عددان | حاصل ضرب | `E4004` |
| `a / b` | عددان | خارج قسمة | `E4004`، و`E4002` إذا كان `b == 0` |
| `a % b` | عددان | باقٍ | `E4004`، و`E4003` إذا كان `b == 0` |
| `-a` | عدد | سالب | `E4004` |

- `/` قسمة عشرية، وليست قسمة أعداد صحيحة.
- `%` باقٍ مبتور: `a - trunc(a / b) * b`. النتيجة تحمل إشارة المقسوم. أمثلة:
  `7 % 3 == 1`، `-7 % 3 == -1`، `7 % -3 == 1`.
- يُفحص المقسوم عليه الصفري قبل الحساب، بما في ذلك `0 / 0` و`0 % 0`.
- يجب أن تكون كل نتيجة حسابية منتهية. إذا كانت النتيجة NaN أو لانهاية، يرفع وقت التشغيل
  `E4006` عند موضع المعامل.
- `+` لا يحوّل ضمنيًا. `"1" + 2` يعطي `E4004`، وليس `"12"` أو `3`.

### 7.3 المقارنة

- `<` و`<=` و`>` و`>=` تقبل معاملين `number` وتعيد `boolean`.
- أي أنواع أخرى تعطي `E4004`.
- ترتيب النصوص والمنطق مؤجل.

### 7.4 المساواة

`==` و`!=` معرفتان في القسم 5.4 ولا ترفعان خطأ أبدًا.

### 7.5 المعاملات المنطقية

- `and` و`or` و`not` تتطلب معاملات `boolean`.
- `a and b`: قيّم `a`؛ إذا لم يكن `boolean` فـ `E4004`؛ إذا كان `false` فأعد `false` بلا
  تقييم `b`؛ وإلا قيّم `b` واشترط أن يكون `boolean` وأعده.
- `a or b`: قيّم `a`؛ إذا لم يكن `boolean` فـ `E4004`؛ إذا كان `true` فأعد `true` بلا
  تقييم `b`؛ وإلا قيّم `b` واشترط أن يكون `boolean` وأعده.
- `not a`: قيّم `a`، واشترط أن يكون `boolean`، وأعد نقيضه.
- `and` و`or` ليستا محدّدتي قيمة: تعيدان دائمًا `boolean`، ولا تعيدان أحد المعاملين كما هو.

### 7.6 الشروط

يجب أن يُقيَّم شرط `if` إلى `boolean`. أي نوع آخر يرفع `E4001` عند موضع الشرط. لا يوجد
مفهوم الصدق (Truthiness).

### 7.7 الاستدعاءات

- هدف الاستدعاء معرّف. يجب أن يُحلّ إلى دالة مستخدم أو إلى `print` المدمجة.
- استدعاء متغير يعطي `E3009`.
- يجب أن يقدم استدعاء دالة المستخدم عدد الوسائط المعلن بالضبط (`E3008`).
- تقبل `print` صفر وسائط أو أكثر.
- تُقيَّم الوسائط من اليسار إلى اليمين قبل تشغيل الدالة.
- تعيد دالة المستخدم القيمة المعطاة لـ `return`؛ والوصول إلى نهاية الجسم يعيد `nil`.
- الاستدعاء الذاتي مسموح. الحد الأقصى لعدد استدعاءات دوال المستخدم النشطة هو **1000**.
  محاولة الاستدعاء رقم 1001 ترفع `E4005` عند موضع الاستدعاء.
- لا تُحسب استدعاءات `print` ضمن حد عمق دوال المستخدم.

## 8. التعليمات والتحكم

### 8.1 تعليمات التعبير

`expr;` يقيّم التعبير ويطرح قيمته في `msf run`. في REPL تُعرض القيمة غير `nil`
(القسم 14).

### 8.2 إعلانات المتغيرات

راجع القسم 6.2. الإعلان تعليمة ولا ينتج قيمة.

### 8.3 تعليمات الإسناد

راجع القسم 6.3.

### 8.4 الكتل

`{ ... }` ينفّذ إعلاناته بالترتيب في نطاق جديد. الكتلة المستقلة مسموحة ومفيدة لتقييد عمر
الارتباط:

```msf
{
    let temporary = 99;
    print(temporary);
}
// temporary غير مرئي هنا
```

### 8.5 تعليمات `if`

```msf
if (condition) {
    // فرع الشرط
} else if (otherCondition) {
    // فرع else-if
} else {
    // فرع else
}
```

- يجب أن يكون الشرط `boolean`.
- يُنفّذ فرع واحد فقط.
- لكل فرع نطاقه الخاص.
- `if` بلا `else` صالح.
- `else if` سكر نحوي لتعليمة `if` داخل فرع `else`، وليس بنية منفصلة.

### 8.6 تعليمات `return`

- `return expr;` يعيد `expr` من أقرب دالة مستخدم.
- `return;` يعيد `nil`.
- `return` خارج أي دالة يعطي `E3011`.
- `return` داخل كتلة متداخلة في دالة يعود من الدالة، لا من الكتلة فقط.

### 8.7 لا تعليمات أخرى

لا توجد في 0.1 حلقات ولا `break` ولا `continue` ولا `throw` ولا `try` ولا `switch` ولا
`match` ولا `defer`. استخدام هذه الكلمات كمعرّفات مسموح ما لم تصبح كلمات محجوزة في إصدار
مستقبلي؛ راجع القسم 15.

## 9. الدوال

### 9.1 الإعلان

```msf
fn name(p1, p2) {
    // الجسم
}
```

- إعلانات `fn` مسموحة فقط في المستوى الأعلى للبرنامج (`E3007` فيما عدا ذلك). يجوز أن تظهر
  في أي موضع بين إعلانات المستوى الأعلى، لكنها تدخل حيّز النفاذ في موضعها النصي.
- يجب أن تكون أسماء المعاملات فريدة داخل الدالة الواحدة (`E3003`).
- لا يجوز أن يشترك متغير ودالة في الاسم نفسه داخل النطاق نفسه (`E3002`).
- لا يجوز أن تحمل الدالة اسم `print` (`E3004`).
- إعلان الدالة لا تنتهي بفاصلة منقوطة.
- يجوز أن تكون الدالة بلا معاملات.

### 9.2 المعاملات والمتغيرات المحلية

- المعاملات ارتباطات محلية قابلة للإسناد.
- المعاملات والمتغيرات المحلية في المستوى الأعلى من جسم الدالة تشترك في نطاق الدالة نفسه.
  إعلان محلي بالاسم نفسه لمعامل يعطي `E3002`.
- يجوز للكتل الداخلية في الجسم حجب المعاملات والمتغيرات المحلية بشكل طبيعي.
- لا يستطيع جسم الدالة الوصول إلى متغيرات المستدعي المحلية (لا نطاق ديناميكي)، ولا يلتقط
  بيئة (لا إغلاقات). ولأن الدوال كلها على المستوى الأعلى، فإن نطاقها الخارجي الوحيد هو
  النطاق العام.

### 9.3 الاستدعاء وعدد الوسائط

- لدوال المستخدم عدد وسائط ثابت. يفحص المحلل الدلالي كل استدعاء مباشر مقابل الإعلان
  (`E3008`).
- لا توجد معاملات افتراضية ولا دوال متغيّرة الوسائط للمستخدم ولا تحميل زائد ولا وسائط
  مسماة ولا اختيارية.
- `print` هي الدالة الوحيدة متغيرة الوسائط.

### 9.4 الاستدعاء الذاتي

الاستدعاء الذاتي المباشر مدعوم:

```msf
fn factorial(n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}
```

اسم الدالة مرئي داخل جسمها. إذا حجب ارتباط محلي اسم الدالة، تصبح الاستدعاءات عبر ذلك الاسم
تعطي `E3009`. لا توجد في 0.1 أسماء بديلة ولا دوال من الدرجة الأولى، لذا تكون الدالة
المحجوبة غير قابلة للوصول داخل ذلك النطاق. هذا نتيجة طبيعية للنطاق المعجمي، وليس قاعدة
خاصة.

### 9.5 القيم المعادة

- الوصول إلى نهاية الدالة يعيد `nil`.
- `return;` يعيد `nil`.
- استدعاء دالة كتعليمة تعبير مسموح؛ وتُطرح قيمته المعادة في وضع `run`.

## 10. الدالة المدمجة `print`

`print` دالة عامة معرفة مسبقًا:

- الاسم: `print`
- عدد الوسائط: صفر أو أكثر
- القيمة المعادة: `nil`
- الأثر الجانبي: كتابة الوسائط المنسّقة إلى المخرجات القياسية، مفصولة بمسافة واحدة،
  متبوعة بـ `\n` واحدة، مع تفريغ المخزن.

يتبع التنسيق القسم 5.5. `print()` يكتب سطرًا جديدًا واحدًا. `print("a", 1, true)` يكتب
`a 1 true\n`. لا تُوضع علامات اقتباس حول النصوص. `print` ليست كلمة محجوزة، ولا يجوز
حجبها أو إعادة إعلانها. استخدام `print` كقيمة بدلًا من دالة مستدعاة يعطي `E3010`.

`print` هي الدالة المدمجة الوحيدة في 0.1. لا توجد أسماء أخرى معرفة مسبقًا.

## 11. تنفيذ البرنامج

### 11.1 خط الأنابيب

يتكون التشغيل من المراحل التالية بالترتيب:

1. قراءة الملف بترميز UTF-8 صارم.
2. تحليل المصدر كاملًا معجميًا. عند أول خطأ معجمي، يُبلَّغ ويتوقف.
3. تحليل تيار الرموز إلى شجرة تجريد. عند أول خطأ نحوي، يُبلَّغ ويتوقف.
4. حل الأسماء والنطاقات وقابلية الإسناد وموضع `return` وموضع الدوال وعدد وسائط الاستدعاء
   المباشر. عند أول خطأ دلالي، يُبلَّغ ويتوقف.
5. تنفيذ إعلانات البرنامج بالتتابع في النطاق العام.
6. تفريغ المخرجات القياسية والخروج.

خطأ معجمي أو نحوي أو دلالي يمنع التنفيذ كليًا. وخطأ وقت التشغيل يوقف التنفيذ عند التعليمة
الفاشلة؛ وتبقى المخرجات المكتوبة سابقًا مكتوبة.

### 11.2 نقطة الدخول

- لا توجد دالة `main` إلزامية.
- تُنفّذ تعليمات المستوى الأعلى بالترتيب النصي.
- البرنامج الفارغ صالح ولا ينتج مخرجات.
- إعلانات `fn` على المستوى الأعلى تنشئ ارتباطاتها عند الوصول إليها، ولا تنفّذ أجسامها.
- يجوز أن ينتهي البرنامج بفاصل سطر أو دونه.

### 11.3 الحتمية والآثار الجانبية

الأثر الجانبي الوحيد القابل للملاحظة في 0.1 هو الكتابة إلى المخرجات القياسية عبر `print`.
لا يوجد إدخال ولا ساعة ولا عشوائية ولا وصول إلى ملفات أو شبكة أو بيئة أو تزامن.

## 12. الأخطاء والتشخيص

### 12.1 قاعدة الفشل السريع

يبلّغ 0.1 عن تشخيص واحد فقط لكل استدعاء، من أول مرحلة فاشلة. لا يحاول التعافي أو عرض
أخطاء متعددة. ويبلّغ REPL عن تشخيص واحد لكل مدخلة ثم يكمل.

### 12.2 حقول التشخيص

كل تشخيص لغوي يحمل:

- رمزًا ثابتًا (`E1001`–`E4006`)،
- شدة مشتقة من المرحلة (`error`)،
- رسالة مقروءة،
- مسار المصدر (`<repl>` في REPL)،
- سطرًا وعمودًا يبدآن من 1،
- تلميحًا اختياريًا.

### 12.3 صيغة النص

تُكتب التشخيصات إلى الخطأ القياسي، بلا ألوان ANSI، بالشكل التالي:

```text
error[E4002]: division by zero
 --> examples/div-zero.msf:7:14
  |
7 |     print(10 / 0);
  |              ^
  = hint: check that the divisor is not zero
```

القواعد:

- السطر الأول بالضبط `error[<code>]: <message>`.
- سطر الموضع يبدأ بمسافة واحدة ثم `--> ` ثم مسار العرض ثم `:` ثم السطر ثم `:` ثم العمود.
- يتسع هامش أرقام الأسطر مع عدد أرقام السطر.
- سطر المؤشر يحتوي `^` بعدد أعمدة المدى، بحد أدنى مؤشر واحد.
- تُحفظ علامات الجدولة في سطر المصدر وفي بادئة المؤشر لتبقى المحاذاة صحيحة في الطرفية.
- سطر التلميح اختياري ويبدأ بـ `  = hint: `.
- مسار العرض هو المسار كما قُدّم في سطر الأوامر، دون تحويل إلى مسار مطلق. ويستخدم REPL
  `<repl>`.
- مقتطف المصدر هو السطر الواحد الذي يقع فيه بداية التشخيص. لا تُسطَّر المدىات متعددة
  الأسطر في 0.1.
- يجوز للمنفّذ اقتطاع الأسطر الطويلة جدًا إلى 120 عمود عرض حول المدى؛ ويبقى السطر والعمود
  في الترويسة مرجعيين. الاقتطاع غير مطلوب في اختبارات المطابقة.
- يجب ألا يتضمن التشخيص العادي تتبّع مكدس. تتبّع المكدس مؤجل.

| الخروج | المعنى |
|---|---|
| `0` | النجاح |

| `2` | خطأ وقت تشغيل |
| `3` | خطأ استخدام سطر الأوامر |
| `4` | خطأ إدخال/إخراج، بما فيه الملف المفقود أو غير المقروء أو UTF-8 غير الصالح |

REPL في الإدخال/الإخراج يخرج بـ `4`.

## 13. عقد سطر الأوامر

الملف التنفيذي هو `msf` (وعلى Windows `msf.exe`). سطح الأوامر في 0.1:

```text
msf run <path>
msf repl
msf --help | -h
msf --version | -v
```

### 13.1 `msf run <path>`

- يقرأ `<path>` بترميز UTF-8 صارم، ويقبل BOM اختياريًا، وينفّذه.
- يقبل أي اسم ملف؛ ويُوصى بامتداد `.msf` لكنه غير مفروض.
- يجوز أن يكون المسار نسبيًا أو مطلقًا ويحتوي مسافات. الاقتباس مسؤولية الصدفة.
- أي معاملات إضافية بعد المسار خطأ استخدام (`E5002`، الخروج 3). معاملات البرنامج مؤجلة.
- عند النجاح يخرج بـ 0 بعد تفريغ المخرجات.
- عند خطأ لغوي يطبع تشخيصًا واحدًا إلى الخطأ القياسي ويخرج بـ 1 أو 2.
- عند خطأ إدخال/إخراج يطبع رسالة `E500x` إلى الخطأ القياسي ويخرج بـ 4.
- تبقى المخرجات المكتوبة قبل خطأ وقت التشغيل في المخرجات القياسية.
- لا يطبع الأمر مسار المصدر ولا الزمن ولا لافتة نجاح.

مثال:

```text
> msf run examples/hello.msf
Hello, MSF!
> echo $LASTEXITCODE
0
```

### 13.2 `msf repl`

راجع القسم 14.

### 13.3 `msf --help`

يطبع الاستخدام وقائمة الأوامر وملخص نطاق 0.1 ورابط التوثيق إلى المخرجات القياسية، ويخرج
بـ 0. مخرجات المساعدة ليست سطح مطابقة؛ الأوامر ورموز الخروج هي.

### 13.4 `msf --version`

يطبع بالضبط `msf 0.1.0` متبوعًا بـ `\n`، ويخرج بـ 0. هذه السلسلة سطح مطابقة.

### 13.5 أخطاء المعاملات

- `msf` بلا معاملات: يطبع الاستخدام إلى الخطأ القياسي ويخرج بـ 3.
- أمر أو خيار غير معروف: `E5001`/`E5002` إلى الخطأ القياسي، الخروج 3.
- `msf run` بلا مسار أو بأكثر من مسار: `E5002`، الخروج 3.
- `msf repl` بمعاملات إضافية: `E5002`، الخروج 3.
- الأوامر والخيارات حساسة لحالة الأحرف.
- `--` ليس فاصلًا في 0.1.

### 13.6 التيارات والترميز

- مخرجات البرنامج العادية إلى المخرجات القياسية.
- التشخيصات وأخطاء الاستخدام إلى الخطأ القياسي.
- تستخدم المخرجات نهايات أسطر `\n` على كل المنصات، بما فيها Windows.
- عند إعادة توجيه المخرجات القياسية، تكون UTF-8 بلا BOM.
- تنسيق الأعداد والقيم ثابت الثقافة ومستقل عن لغة نظام التشغيل.
- لا تُصدر ألوان ANSI في 0.1.

## 14. عقد REPL

### 14.1 نموذج الجلسة

- يحتفظ REPL بنطاق عام واحد وبيئة تشغيل واحدة مستمرين بين المدخلات.
- الإعلانات تستمر: `let` أو `var` أو `fn` تُدخل في مدخلة تصبح مرئية في المدخلات اللاحقة.
- كل مدخلة تُحلَّل معجميًا ونحويًا ودلاليًا وتُنفّذ كجزء برنامج مكتمل.
- خطأ وقت الترجمة يطبع تشخيصًا ويترك الحالة كلها دون تغيير.
- خطأ وقت التشغيل يطبع تشخيصًا و**يتراجع عن جميع الإعلانات والإسنادات التي أجرتها تلك
  المدخلة** إلى الحالة السابقة للمدخلة. تبقى المخرجات المطبوعة سابقًا مطبوعة. يحافظ ذلك
  على اتساق جدول الرموز الدلالي وبيئة التشغيل.
- `:quit` و`:help` وEOF يديرها REPL، لا اللغة.

### 14.2 الإدخال والمطالبات

- يُستخدم الوضع التفاعلي عندما يكون الإدخال القياسي طرفية (`Console.IsInputRedirected`
  تساوي false في المنفّذ المرجعي).
- يطبع الوضع التفاعلي لافتة قصيرة والمطالبة `msf> ` إلى المخرجات القياسية.
- إذا أبلغ المحلل أو المعجم عن مدخلة غير مكتملة (خطأ موضعه EOF، بما فيه نص أو تعليق كتلة
  غير منتهٍ)، يطبع REPL مطالبة المتابعة `...> ` ويقرأ أسطرًا إضافية.
- السطر الفارغ أثناء انتظار المتابعة ينهي المدخلة ويبلّغ عن تشخيص الإدخال غير المكتمل
  المعلّق. ثم تعود الجلسة إلى `msf> `.
- تُنفّذ المدخلة المكتملة فور إدخال سطرها الأخير.
- يُعرف الأمران `:quit` و`:help` فقط في بداية مدخلة جديدة، بعد إزالة الفراغات المحيطة.
  وليسا معرّفين لغويين.
- `:quit` يخرج بـ 0. وEOF يخرج بـ 0.
- الأمر المجهول الذي يبدأ بـ `:` يطبع رسالة بأسلوب سطر الأوامر ويعود إلى المطالبة؛ ولا
  يخرج.
- سلوك Ctrl+C يعتمد على الطرفية وليس جزءًا من عقد مطابقة 0.1.

### 14.3 الوضع غير التفاعلي

عند إعادة توجيه الإدخال القياسي:

- لا تُطبع لافتة ولا مطالبات.
- يُقرأ الإدخال سطرًا بسطر. كل سطر يبدأ مدخلة جديدة؛ وإذا كانت المدخلة غير مكتملة تُضاف
  الأسطر اللاحقة حتى تكتمل أو يُبلغ EOF.
- تظل نتائج تعليمات التعبير تُعرض تلقائيًا.
- تخرج العملية بـ 0 ما لم يفشل بدء الإدخال/الإخراج.

يوجد هذا الوضع لتسهيل اختبار REPL بأنبوب إدخال إلى `msf repl`.

### 14.4 العرض التلقائي

في REPL فقط، كل تعليمة تعبير على المستوى الأعلى وقيمتها ليست `nil` تُنسّق وفق القسم 5.5
وتُطبع إلى المخرجات القياسية متبوعة بـ `\n`. هذا تسهيل إخراجي، وليس ميزة لغوية. الإعلانات
والإسنادات وتعليمات `if` وإعلانات الدوال لا تُعرض تلقائيًا. `print(...)` يعيد `nil`، فلا
يُعرض له قيمة ثانية.

مثال (تفاعلي أو بأنبوب):

```text
let x = 5;
x * 2;
print("done");
```

المخرجات:

```text
10
done
```

المدخلة الأولى لا تنتج مخرجات؛ والثانية تنتج `10\n`؛ والثالثة تنتج `done\n`.

## 15. الإصدار والتوافق

- تستخدم ملفات مصدر MSF Lang امتداد `.msf` بالاصطلاح؛ ويقبل سطر الأوامر أي مسار.
- إصدار اللغة `0.1.0`. سلسلة إصدار سطر الأوامر بالضبط `msf 0.1.0`.
- 0.1 إصدار ما قبل 1.0. يجوز للإصدارات الفرعية اللاحقة إضافة ميزات، لكن لا يجوز لها تغيير
  معنى برنامج 0.1 مطابق بصمت. التغييرات الكاسرة تتطلب رفع الإصدار الفرعي وملاحظة هجرة في
  سجل التغييرات.
- الكلمات المحجوزة الجديدة خطر توافق. لا يحجز 0.1 كلمات للميزات المؤجلة مثل `while` و`for`
  و`break` و`continue` و`class` و`import` و`match`. أي إصدار مستقبلي يقدمها ككلمات محجوزة
  يجب أن يوثّق الكسر ويقدم إرشادات الهجرة.
- إصدار المواصفات `0.1.0-draft.1` ليس إصدارًا معتمدًا. يجب اعتماد هذه الوثيقة قبل بدء
  التنفيذ.

## 16. المطابقة

يتوافق المنفّذ مع MSF Lang 0.1 إذا حقق كل عبارة معيارية في هذه الوثيقة واجتاز مجموعة
المطابقة المعرفة في [`docs/ar/IMPLEMENTATION-PLAN.md`](IMPLEMENTATION-PLAN.md).

تُعرّف المطابقة بالسلوك القابل للملاحظة:

- بايتات المخرجات القياسية (بعد توحيد نهايات الأسطر إلى `\n`)،
- تشخيصات الخطأ القياسي (الرمز والسطر والعمود، والصيغة الكاملة حيث حُددت)،
- رمز الخروج،
- حالة REPL بين المدخلات.

التفاصيل التنفيذية مثل شكل شجرة التجريد وتخطيط الذاكرة وصياغة الرسائل خارج الأنماط
الموثقة ليست سطح مطابقة. أما **رموز** التشخيص و**مواضعها** فهي سطح مطابقة.

لم تُنفَّذ أي عملية مطابقة بعد. ستُنشأ مجموعة الاختبارات في المرحلة الثانية، وسيُدعم كل
ادعاء بنجاح اختبارات بأمر فعلي ومخرجاته.

## 17. أمثلة كاملة

### 17.1 مرحبًا MSF

```msf
print("Hello, MSF!");
```

المخرجات:

```text
Hello, MSF!
```

### 17.2 المتغيرات والأنواع

```msf
let name = "Mustafa";
var visits = 1;
visits = visits + 1;

print("Hello,", name);
print("Visits:", visits);
print("Same?", 1 == 1, 1 == "1", nil == nil);
```

المخرجات:

```text
Hello, Mustafa
Visits: 2
Same? true false true
```

### 17.3 الحساب والأسبقية

```msf
print(1 + 2 * 3);
print((1 + 2) * 3);
print(-7 % 3);
print(7.5 / 2);
```

المخرجات:

```text
7
9
-1
3.75
```

### 17.4 الشروط

```msf
fn classify(n) {
    if (n < 0) {
        return "negative";
    } else if (n == 0) {
        return "zero";
    } else {
        return "positive";
    }
}

print(classify(-4), classify(0), classify(9));
```

المخرجات:

```text
negative zero positive
```

### 17.5 الاستدعاء الذاتي

```msf
fn factorial(n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

fn fibonacci(n) {
    if (n < 2) {
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}

print(factorial(10));
print(fibonacci(10));
```

المخرجات:

```text
3628800
55
```

### 17.6 المنطق قصير الدائرة

```msf
print(false and (1 / 0 == 0));
print(true or (1 / 0 == 0));
print(not false);
```

المخرجات:

```text
false
true
true
```

لا تُقيَّم القسمة أبدًا، فلا يحدث `E4002`.

### 17.7 خطأ: إسناد إلى ثابت

```msf
let x = 10;
x = 20;
```

التشخيص المتوقع (الشكل):

```text
error[E3005]: cannot assign to immutable 'x'; declare it with 'var'
 --> immutable.msf:2:1
  |
2 | x = 20;
  | ^
  = hint: change the declaration to 'var x = 10;' if reassignment is intended
```

رمز الخروج: `1`. لا يُنفّذ شيء لأن التحليل الدلالي يفشل قبل التنفيذ.

### 17.8 خطأ: عدم تطابق الأنواع وقت التشغيل

```msf
print(1 + "2");
```

التشخيص المتوقع (الشكل):

```text
error[E4004]: invalid operand types for '+': number and string
 --> type-error.msf:1:7
  |
1 | print(1 + "2");
  |       ^
```

رمز الخروج: `2`.

### 17.9 خطأ: اسم غير معرف

```msf
print(total);
```

التشخيص المتوقع (الشكل):

```text
error[E3001]: undefined name 'total'
 --> undefined.msf:1:7
  |
1 | print(total);
  |       ^^^^^
```

رمز الخروج: `1`.

### 17.10 جلسة REPL

```text
msf> let x = 5;
msf> x * 2;
10
msf> fn square(n) {
...>     return n * n;
...> }
msf> square(x);
25
msf> :quit
```

تظهر مطالبة المتابعة بعد السطر الأول من الدالة لأن المحلل يصل إلى EOF وهو يتوقع `}`
(`E2010`).

## 18. قائمة اعتماد المواصفات

تكون المواصفات جاهزة للتنفيذ عندما يؤكد مالك المشروع:

- [ ] مجموعة ميزات 0.1 وسجل الميزات المؤجلة صحيحان.
- [ ] دلالات `let` / `var` والنطاقات الكتلية معتمدة.
- [ ] الدوال على المستوى الأعلى فقط، بلا رفع، مع استدعاء ذاتي مباشر، وبلا استدعاء متبادل،
  مقبولة.
- [ ] الشروط المنطقية الصارمة وغياب مفهوم الصدق مقبولان.
- [ ] `print` كدالة مدمجة محجوزة متغيرة الوسائط مقبولة.
- [ ] القواعد النحوية، خصوصًا الفواصل المنقوطة والأقواس والاستدعاء بالمعرّفات فقط، معتمدة.
- [ ] رموز التشخيص وصيغتها ورموز الخروج معتمدة.
- [ ] عقد سطر الأوامر وREPL، بما فيه التراجع في REPL والعرض التلقائي، معتمد.
- [ ] خطة التنفيذ والمراحل ومصفوفة الاختبارات معتمدة.
- [ ] اختيار هوية العلامة التجارية يُعالج كبوابة منفصلة (Gate B).

بعد اعتماد هذه البنود يبدأ التنفيذ عند المرحلة الأولى في خطة التنفيذ. لن يُكتب أي كود
للمحرك قبل قبول هذه القائمة.
