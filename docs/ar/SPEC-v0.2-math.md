# MSF Lang v0.2 — إضافة الرياضيات (مسودة)

**الحالة:** مسودة مرافق لـ [`SPEC-v0.2-practical.md`](SPEC-v0.2-practical.md). الإنجليزية مرجعية.

## المدمجات

| الاسم | عدد الوسائط | المعنى |
|---|---|---|
| `abs(x)` | 1 | القيمة المطلقة |
| `sqrt(x)` | 1 | الجذر التربيعي، `x >= 0` |
| `floor(x)` | 1 | التقريب لأسفل |
| `ceil(x)` | 1 | التقريب لأعلى |
| `round(x)` | 1 | تقريب النصف بعيدًا عن الصفر |
| `pow(x, y)` | 2 | فحص `x^y`؛ نتيجة غير منتهية → `E4006` |
| `min(a, b)` | 2 | الأصغر |
| `max(a, b)` | 2 | الأكبر |

كل الوسائط يجب أن تكون `number`. غير ذلك يؤدي إلى `E4009`.
