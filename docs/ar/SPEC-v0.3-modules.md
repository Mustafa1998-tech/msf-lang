# MSF Lang v0.3 — الوحدات (مقبولة)

**إصدار المواصفة:** `0.3.0`
**الحالة:** مقبولة بموجب ADR-0021 (2026-11-17). مُنفّذة في `msf 0.3.0-rc.1`. النص الإنجليزي مرجعي.

## الهدف

- تنظيم الكود: وحدات ملفات قابلة لإعادة الاستخدام مع تبعية موجّهة.
- مشاريع متعددة الملفات بدون تلويث النطاق العام.
- تنفيذ حتمي؛ الحد للمكتبات المحلية فقط.

## نحو

```ebnf
module-decl   = "import" , string , ";" ;
export-decl   = "export" , ( function-decl | var-decl ) ;
member-expr   = identifier , "." , identifier ;
qualified-call-expr = identifier , "." , identifier , "(" , arguments? , ")" ;
```

```msf
// math.msf
export fn square(n) { return n * n; }
export var PI = 3.5;

// main.msf
import "./math.msf";
print(math.square(9));   // 81
print(math.PI);          // 3.5
```

## الدلالات

- `import "path";` يقيّد مسارًا نسبيًا بامتداد `.msf`؛ المسارات المطلقة أو الامتدادات الأخرى تفشل بـ `E4012`.
- اسم الوحدة هو اسم الملف بدون الامتداد، ويجب أن يكون معرّفًا صالحًا.
- المسؤول `math` يظهر في النطاق المحلي فقط؛ الوصول إلزامي مؤهّل: `math.square`، و`square` وحدها تفشل بـ `E3001`.
- الأسماء المعلنة بـ `export` فقط مرئية من الخارج؛ غير المعلنة خاصة بالوحدة (`E4013`).
- كل وحدة تُقرأ وتُنفذ مرة واحدة على الأكثر لكل عملية/جلسة REPL، وتنفذ قبل ملف الاستيراد وبترتيب التبعية.
- الاستيراد الدوري ممنوع: `E4014` مع ذكر سلسلة الدورة.
- `import` داخل كتلة/دالة ممنوع: `E3015`. `export` خارج المستوى الأعلى ممنوع: `E3016`.
- استخدام الوحدة كقيمة ممنوع: `E3017`.
- أخطاء وقت التشغيل داخل الوحدة تحمل مسار ملف الوحدة.

## توافق

بدون استيراد محلي نسبي فقط. `import` و`export` كلمتان محجوزتان الآن.

## حدود معروفة

- لا يوجد `as alias` بعد.
- لا يوجد إعادة تصدير.
- لا توجد حزم/سجلات.
- إعادة استيراد نفس المسار في نفس النطاق = `E3002`.
