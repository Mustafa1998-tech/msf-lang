# MSF Lang v0.2 — "Practical Programming" إضافة عملية (مسودة)

**نسخة المواصفة:** `0.2.0-draft.1`  
**التاريخ:** 2026-11-16  
**الحالة:** مسودة. هذه الوثيقة تصف إضافات v0.2 التراكمية على [`SPEC-v0.1.md`](SPEC-v0.1.md). الإنجليزية مرجعية عند التعارض.

> v0.2 تمتد على v0.1 بأصغر مجموعة عملية: **التكرار (`while`)**، **القوائم (list)**، و**دالتان مدمجتان للقوائم/النصوص (`len`, `append`)**. باقي مواصفات v0.1 تبقى كما هي ما لم يُذكر خلاف ذلك هنا.

## 1. لماذا هذه الإضافة؟

- v0.1 عملي كمنصة صغيرة، لكن البرامج العادية تحتاج تكرارًا وقوائم متغيرة.
- هذه الإضافة تهدف لفائدة عملية مباشرة بدون إضافة وحدات/شبكات/ملفات خارج النطاق.

### 1.1 مشمول في v0.2

| المجال | يتضمن |
|---|---|
| التكرار | `while (condition) { block }` بشرط boolean، مع `break;` و`continue;` |
| المجموعات | نوع `list`: مصفوفة ديناميكية غير متجانسة |
| الفهرسة | قراءة/كتابة عناصر القائمة (`xs[i]`, `xs[i] = value;`) |
| دوال مدمجة | `len(listOrString)`, `append(list, value)` |
| العرض | طباعة/REPL للقوائم `[a, b]` |

## 2. `while` مع `break` و`continue`

```msf
var i = 0;
var total = 0;
while (i < 10) {
    if (i == 5) { break; }
    total = total + i;
    i = i + 1;
}
```

- الشرط يجب أن يكون `boolean`. غير ذلك يؤدي إلى `E4001`.
- `break` يخرج من أقرب `while`.
- `continue` ينتقل للتكرار التالي.
- داخل جسم الحلقة، لكل تكرار Scope مستقل.

## 3. القوائم

### 3.1 بناء ومؤشر

```ebnf
list-literal    = "[" , [ expression , { "," , expression } ] , "]" ;
postfix-expr    = call-or-primary , { "[" , expression , "]" } ;
assignment-stmt = identifier , "=" , expression , ";"
                | identifier , "[" , expression , "]" , "=" , expression , ";" ;
```

- `xs[i]` يقرأ العنصر ذي الفهرس `i`.
- `xs[i] = value;` يُحدّث العنصر في القائمة نفسها.
- الفهرس يجب أن يكون `number` صحيحًا وفي النطاق `[0, len(xs))`.
  - غير صحيح/خارج النطاق: `E4007`.

### 3.2 النوع والدلالات

- اسم النوع في الرسائل: `list`.
- العناصر غير متجانسة؛ كل عنصر يحتفظ بنوعه v0.1.
- المساواة بين قائمتين بالمرجع فقط. لا توجد مساواة عنصر-بن-عنصر.
- العرض من `print`/REPL: `[e0, e1, ...]`، والنصوص المداخلة تُقتبس داخل القائمة لتجنب الالتباس.

### 3.3 `len`

- الدالة المدمجة `len(x)` تقبل قائمة أو نصًا.
- لقائمة: عدد العناصر. لنص: عدد قيم Unicode القياسية.
- غير ذلك: `E4008`.

### 3.4 `append`

- `append(list, value)` تُلحق القيمة بالقائمة **في مكانها** وتعيد `nil`.
- الوسيط الأول يجب أن يكون `list`. غير ذلك: `E4008`.

## 4. الأمثلة

```msf
var xs = [1, 2, 3];
xs[1] = 99;
append(xs, 7);
print(xs);       // [1, 99, 3, 7]
print(len(xs));  // 4
print(len("مرحبا")); // 5
```
